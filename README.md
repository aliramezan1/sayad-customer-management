# سامانه جامع مدیریت مشتریان، چک‌های صیادی و اعتبارسنجی بانکی 💎
### (Bank Central CBI & Pasargad vBank Integration)

سامانه یکپارچه و پیشرفته برای استعلام، اعتبارسنجی، مدیریت مشتریان و نظارت بر چک‌های صیادی با اتصال مستقیم به درگاه‌های رسمی بانک مرکزی و بانک پاسارگاد.

---

## 🌟 ویژگی‌های کلیدی سامانه

1. **استعلام صیادی و شناسایی خودکار هویت مشتریان:**
   - استعلام برخط شناسه ۱۶ رقمی چک‌ها از سامانه بانک مرکزی.
   - حل خودکار سوالات امنیتی و کپچا با هوش مصنوعی و OCR پیشرفته.
   - کشف و استخراج نام و نام خانوادگی صاحب چک، وضعیت صیادی و رنگ اعتباری (سفید، زرد، نارنجی، قهوه‌ای، قرمز).

2. **اعتبارسنجی هوشمند از سامانه بانک پاسارگاد:**
   - اتصال مستقیم به درگاه خدمات عمومی بانک پاسارگاد (`vbank.bpi.ir`).
   - دریافت آنی ۳ شاخص کلیدی:
     - 🚚 **مبلغ و تعداد چک‌های در راه** (`onGoingAmount`)
     - ✅ **مبلغ و تعداد چک‌های رفع سوءاثر شده** (`clearedAmount`)
     - ⚠️ **مبلغ و تعداد چک‌های برگشتی** (`bouncedAmount`)
   - پیش‌پیکربندی ۹ هولدر رسمی (دارندگان چک) با کدملی‌های معتبر جهت انتخاب سریع.

3. **پروفایل اختصاصی برای هر مشتری:**
   - صفحه پروفایل جامع با کارت‌های مالی، نمودار نسبت‌ها و فهرست چک‌های مرتبط.
   - امکان ثبت چک جدید، ویرایش اطلاعات مشتری و دریافت گزارش عملکرد.

4. **رابط کاربری مدرن (SPA) با پشتیبانی کامل از تم روز و شب:**
   - طراحی Glassmorphism لوکس با فونت زیبای **وزیرمتن**.
   - دکمه تغییر حالت روز (Light Mode) و شب (Dark Mode) با ذخیره تنظیمات در مرورگر.
   - جستجوی زنده (Real-time Search) روی نام مشتریان، شماره ملی، سریال چک و شناسه صیادی.

5. **مدیریت کامل اطلاعات (CRUD):**
   - قابلیت افزودن، ویرایش و حذف مشخصات مشتریان و چک‌ها.

6. **زمان‌بندی خودکار روزانه (Daily Background Scheduler):**
   - سرویس پس‌زمینه هوشمند جهت استعلام و بروزرسانی خودکار روزانه وضعیت اعتباری تمام چک‌ها.

7. **خروجی اکسل پیشرفته (Excel Export):**
   - تولید و دانلود گزارش راست‌به‌چپ (RTL) به فرمت `.xlsx` شامل تمام مشتریان، چک‌ها، هولدرها و مبالغ اعتبارسنجی.

## 🚀 راهنمای نصب و اجرای محلی

### پیش‌نیازها:
- پایتون نسخه ۳.۱۰ یا بالاتر

### ۱. نصب وابستگی‌ها:
```bash
pip install -r requirements.txt
```

### ۲. اجرای سرور وب‌اپلیکیشن:
- **در ویندوز:** فقط کافیست روی فایل `run.bat` دوبار کلیک کنید.
- **یا در ترمینال:**
```bash
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload
```

سپس در مرورگر خود آدرس زیر را باز نمایید:
👉 **`http://127.0.0.1:8000`**
